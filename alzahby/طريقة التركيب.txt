قالب Alzahby — منصة QurTap (استاندات NFC و QR الذكية)
=========================================================

التركيب
-------
1. من لوحة ووردبريس: المظهر ← قوالب ← أضف جديد ← رفع قالب ← اختر alzahby.zip ← فعّل.
   (عند التفعيل يتم إنشاء الجداول: wp_alz_profiles و wp_alz_links و wp_alz_stands تلقائياً)
2. الإعدادات ← الروابط الدائمة ← اختر "اسم المقالة" (/%postname%/) ← حفظ.
3. لوحة ووردبريس ← QurTap ← إعدادات القالب:
   • رقم واتساب استقبال الطلبات
   • نصوص الصفحة الرئيسية والعرض
   • (اختياري) Google Client ID و Secret لتسجيل الدخول بجوجل
4. تأكد أن الموقع يرسل بريداً (إضافة SMTP مثل WP Mail SMTP) — مطلوب لرابط الدخول السحري.

المسارات
--------
  /                         الصفحة الرئيسية التسويقية
  /dashboard/               لوحة تحكم العميل
  /dashboard/login/         تسجيل الدخول (جوجل / رابط سحري / كلمة مرور)
  /s/CODE                   الرابط المطبوع على الاستاند (QR + NFC) — ثابت للأبد
  /u/ID                     الرابط الدائم لصفحة النشاط
  /اسم-النشاط               الرابط المختصر لصفحة النشاط

تجهيز الاستاندات للطباعة
-----------------------
QurTap ← تصميم الاستاندات (QR):
  1. اختار العدد (50 / 100 / أي عدد حتى 500) واسم الدفعة.
  2. اختار الصيغة: PDF للطباعة (صفحة لكل استاند) أو ZIP صور PNG + ملف CSV بالأكواد.
  3. اضغط "توليد وتحميل" — كل تصميم عليه QR فريد وكود التفعيل مكتوب تحته.
  • تقدر تغيّر صورة القالب من مكتبة الوسائط، وتحرّك مربع الـ QR بالسحب في المعاينة ثم "حفظ التصميم".
  • "إعادة تحميل دفعة سابقة" يعيد طباعة نفس الأكواد بدون توليد أكواد جديدة.
اكتب نفس رابط الـ QR (print_url في ملف CSV) على شريحة NFC للاستاند.
العميل يمسح الكود وهو مسجّل دخول فيُربط الاستاند بصفحته تلقائياً،
ويفضل الكود شغال مهما غيّر العميل محتوى صفحته أو رابطها.

تسجيل الدخول بجوجل (مجاني)
-------------------------
1. console.cloud.google.com ← APIs & Services ← Credentials ← Create OAuth client ID ← Web application.
2. Authorized redirect URI:  https://موقعك/dashboard/login/google-callback/
3. انسخ Client ID و Client Secret إلى إعدادات القالب.

الحماية
-------
• كل عميل يعدّل صفحته فقط: الصفحة تُحدَّد من حساب المستخدم المسجّل، ولا يُقبل أي معرّف صفحة من المتصفح.
• كل عمليات الحفظ عبر REST API مع X-WP-Nonce، وكل نماذج الدخول والإعدادات محمية بـ nonce.
• ربط الاستاند ذرّي (لا يمكن ربط استاند مربوط لغيرك) مع حد 15 محاولة في الساعة ضد تخمين الأكواد.
• الصور: JPG / PNG / WEBP فقط حتى 2MB (SVG ممنوع).
• الروابط: يُسمح فقط بـ https / http / tel / mailto.
• العملاء لا يدخلون wp-admin، وحسابات الإدارة لا تدخل بالرابط السحري أو جوجل.

ملاحظة عن إضافات الكاش
----------------------
صفحات العملاء خفيفة جداً (بدون wp_head). عند الحفظ يتم مسح الكاش تلقائياً لـ LiteSpeed و WP Rocket و W3 Total Cache.
مع أي إضافة كاش أخرى: استثنِ المسارات /dashboard/* و /s/* من الكاش.
