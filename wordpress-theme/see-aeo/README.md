# See AEO — قالب ووردبريس

قالب ووردبريس عربي (RTL) لشركة **See AEO** المتخصصة في خدمات **SEO · AEO · GEO · تصميم المواقع**.
تصميم داكن فاخر، خط **Cairo**، قائمة علوية زجاجية (glassy)، وأيقونات SVG خفيفة وسريعة.

عند رفعه على ووردبريس يظهر بنفس شكل ملف المعاينة `see-aeo-preview.html` تماماً.

---

## التثبيت

1. اضغط مجلد `see-aeo` في ملف ZIP باسم `see-aeo.zip`.
   ```bash
   cd wordpress-theme
   zip -r see-aeo.zip see-aeo
   ```
2. في لوحة تحكم ووردبريس: **المظهر ← القوالب ← أضف جديد ← رفع قالب** ← اختر `see-aeo.zip` ← **تثبيت** ثم **تفعيل**.

---

## الإعداد بعد التفعيل

### 1) الصفحة الرئيسية (تظهر كل الأقسام)
- أنشئ صفحة فارغة باسم «الرئيسية».
- من **الإعدادات ← القراءة** اختر «صفحة ثابتة» واجعلها الصفحة الأمامية.
  القالب يستخدم `front-page.php` تلقائياً لعرض الهيرو والخدمات والأعمال... إلخ.

### 2) القائمة العلوية (اختياري)
القالب يعرض قائمة افتراضية جاهزة. لتخصيصها:
- **المظهر ← القوائم** ← أنشئ قائمة وعيّنها للموقع **«القائمة الرئيسية»**.
- أضف **روابط مخصصة** بهذه العناوين (للصفحة الواحدة):

  | الرابط | النص |
  |--------|------|
  | `#hero` | الرئيسية |
  | `#services` | خدماتنا |
  | `#blog` | المدونة |
  | `#works` | أعمالنا |
  | `#about` | من نحن |
  | `#contact` | تواصل معنا |

### 3) اللوجو
- **المظهر ← تخصيص ← هوية الموقع ← شعار** وارفع شعارك.
- يوجد شعار SVG جاهز في `assets/img/logo.svg` يمكنك رفعه، وإن لم تضع شعاراً يظهر شعار `SeeAEO` الافتراضي.

---

## المميزات
- تصميم RTL عربي بالكامل بخط Cairo.
- قائمة زجاجية عائمة + زر «ملف الأعمال».
- أيقونات SVG خطية خفيفة (بدل الإيموجي) — أسرع وأنظف.
- خلفية الهيرو بجسيمات Canvas متحركة.
- أنيميشن ظهور عند التمرير + عدّادات رقمية.
- نموذج تواصل مع تحقق من المدخلات.
- متجاوب بالكامل (موبايل / تابلت / ديسكتوب).
- يدعم الشعار المخصص، القوائم، والصور البارزة.

## بنية الملفات
```
see-aeo/
├── style.css            # ترويسة القالب + نظام التصميم الكامل
├── functions.php        # التهيئة، تحميل Cairo والأنماط، القوائم، الـ walker
├── header.php           # الهيدر + القائمة الزجاجية + قائمة الموبايل
├── footer.php           # الفوتر
├── front-page.php       # الصفحة الرئيسية بكل الأقسام
├── index.php            # المدونة / الأرشيف
├── single.php           # المقال المفرد
├── page.php             # الصفحة المفردة
└── assets/
    ├── js/main.js       # كل التفاعلات (قائمة، جسيمات، عدّادات، النموذج)
    └── img/logo.svg     # شعار SVG جاهز
```

> ملف `see-aeo-preview.html` في جذر المستودع هو معاينة ثابتة مطابقة تُفتح مباشرة في المتصفح دون ووردبريس.
