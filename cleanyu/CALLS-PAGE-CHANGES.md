# تعديلات صفحة المكالمات – قالب cleanyu

تم دمج تعديلات `modifiedfilesonly` داخل القالب الأصلي `cleanyu` مع استكمال المميزات المطلوبة.

## الملفات المعدّلة

| الملف | التعديل |
|---|---|
| `components/packs/AjaxCenter/callupdate.php` | حفظ حقل `calltype` (phone / whatsapp) مع كل مكالمة + تنظيف اسم الصفحة |
| `components/packs/#footer/js/setup.js` | مُعالج واحد لكل أزرار الاتصال يرسل نوع الاتصال تلقائياً |
| `components/packs/callnumber/setup.php` | عمود "نوع الاتصال" + 3 كروت عدّادات + وقت 12 ساعة + زر التقرير الشهري |
| `components/packs/custom-fields/UI/style.css` | أنماط الكروت والشارات وزر التقرير |

## المميزات

1. **نوع الاتصال** – عمود جديد بجانب اسم الصفحة يوضح إن كان العميل ضغط زر "اتصل بنا" أم "واتساب".
2. **العدّادات** – ثلاثة كروت جنب بعض (واتساب / هاتفي / الإجمالي) وكل كارت قابل للضغط لفلترة الجدول.
3. **التوقيت** – عرض الوقت بنظام 12 ساعة مع "صباحاً / مساءً".
4. **تقرير PDF شهري** – زر صغير أعلى الصفحة يفتح تقرير آخر شهر جاهزاً للطباعة/الحفظ كـ PDF، ويحتوي على ملخص الأعداد وأكثر الصفحات اتصالاً وجدول تفصيلي بكل المكالمات.

## ملاحظات

- السجلات القديمة المسجّلة قبل هذا التحديث ليس لها `calltype` فتظهر بشارة "غير محدد"، وعددها موضّح أسفل كارت الإجمالي.
- أزرار الاتصال المرصودة: `.btn-phone` و `.btn-whatsapp` و `.popup-phone` و `.popup-whatsapp` وأي رابط `tel:` أو `wa.me`.
- التقرير محمي بصلاحية `manage_options` و nonce، ويُفتح عبر `admin-post.php`.
